# 🎬 DVD Rental Dashboard

## 📌 Project Overview

DVD Rental Dashboard merupakan proyek visualisasi dan analisis data yang dikembangkan menggunakan **Microsoft Power BI**. Dashboard ini dirancang untuk membantu memahami performa bisnis penyewaan DVD melalui visualisasi data yang interaktif dan mudah dipahami.

Analisis difokuskan pada beberapa aspek bisnis, seperti **pendapatan (income)** dan **kategori atau genre film**, sehingga pengguna dapat memperoleh gambaran mengenai performa bisnis berdasarkan data yang tersedia.

## 🎯 Project Objectives

Proyek ini bertujuan untuk:
* Menganalisis data bisnis pada sistem DVD Rental.
* Memvisualisasikan informasi pendapatan melalui dashboard interaktif.
* Mengidentifikasi performa berdasarkan kategori atau genre film.
* Menyajikan data dalam bentuk visual agar lebih mudah dipahami dan digunakan untuk mendukung analisis bisnis.

---
## 📊 Dashboard Pages

### 🏠 Home

Halaman utama yang berfungsi sebagai landing page dan navigasi menuju halaman analisis dashboard.

### 💰 Income Analysis

Halaman yang menyajikan analisis terkait pendapatan dari bisnis DVD Rental melalui visualisasi data interaktif.

### 🎞️ Genre Analysis

Halaman yang menampilkan analisis data berdasarkan kategori atau genre film untuk membantu memahami distribusi dan performa masing-masing genre.

---

## 🛠️ Tools Used

* **Microsoft Power BI** – Data visualization dan dashboard development
* **Power Query** – Data transformation dan preparation
* **DAX** – Data analysis dan calculation
